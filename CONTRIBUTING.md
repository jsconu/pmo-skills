# Contributing

Every issue is judged against the bar in [`SCOPE.md`](./SCOPE.md). Read it first.

## Where each request goes

| You have | Go to |
| --- | --- |
| A case a skill got wrong | [Case issue](https://github.com/jsconu/pmo-skills/issues/new?template=case.yml) |
| A situation you'd like a skill for | [Idea issue](https://github.com/jsconu/pmo-skills/issues/new?template=idea.yml) |
| A question, or "how do I...?" | [Discussions](https://github.com/jsconu/pmo-skills/discussions) |

Pull requests are open to collaborators only, so describe the case in an issue instead.

## Writing a good case

- **Fictional only.** Change every name, company, date and figure. Never paste real project material.
- **Short.** The packet a PM would paste, the answer you got, and the call you would have made. If it doesn't fit on one screen, cut it.
- **One problem per issue.**
- **Say what evidence would change your call.** That's usually the most useful line.

With your permission, accepted cases are credited by name in `CHANGELOG.md` and may become a published teaching case.
