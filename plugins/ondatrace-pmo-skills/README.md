# Ondatrace PMO Skills

Agent skills for project managers, sponsors and PMO leaders, by Justin Scoville, PMP, PgMP. They are the checks a PM runs on a meeting, a status report, a slipped date or a steering agenda before anything goes in front of a sponsor.

AI assistants are quick to write a status report and quick to raise a risk. They are much worse at telling a forecast from a commitment, a suggestion from a decision, and a slip that still has ten days of buffer from one that collides. These skills are small, plain-language methods that hold an assistant to that standard.

## What's included

The 25 skills are grouped by the moment you need them:

- **Frame the work:** interview the sponsor, draft the charter, find the projects, prioritize the backlog.
- **Run the week:** debrief the meeting, write the weekly update, triage the risks, draft the stakeholder update.
- **Test the status:** challenge my status, reconcile the dates, trace the impact, review a change request.
- **Run the portfolio:** prep the portfolio review, build the portfolio report, find capacity conflicts, group portfolio risks, choose today's focus.
- **Follow the decision:** check the decision, trace a decision, plan the handoff, plan change adoption.
- **Measure and learn:** review the budget, check the success metrics, find recurring lessons, run the retrospective.

Not sure which one fits? Ask for **ask-justin** and describe where you are in the week.

## How it works

Every skill works only from the material you paste or attach in the conversation. The plugin has no connectors, runs no scripts and sends nothing anywhere. If you state a lasting preference, a skill asks your permission before saving it to your assistant's own memory, and never saves confidential project content. It is free and MIT licensed.
