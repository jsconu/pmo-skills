# Run the week

The weekly rhythm of one project: meetings, status, risks and messages.

| Skill | What it does | Claude upload |
| --- | --- | --- |
| **[debrief-the-meeting](./debrief-the-meeting/SKILL.md)** | Turn a meeting transcript or notes into a handoff that separates what was said, what was decided and what was accepted, with owners and dates left blank where nobody gave them. | [Download](https://github.com/jsconu/pmo-skills/releases/latest/download/debrief-the-meeting.zip) |
| **[draft-the-stakeholder-update](./draft-the-stakeholder-update/SKILL.md)** | Draft an escalation, customer update or stakeholder message from agreed facts, keeping every material risk, off-track status or open high-severity issue visible rather than softened. | [Download](https://github.com/jsconu/pmo-skills/releases/latest/download/draft-the-stakeholder-update.zip) |
| **[triage-the-risks](./triage-the-risks/SKILL.md)** | Read a task list, dependency export and current risk log and find the emerging exposures, each with its trigger, the work affected and a response worth considering (avoid, mitigate, transfer or accept). | [Download](https://github.com/jsconu/pmo-skills/releases/latest/download/triage-the-risks.zip) |
| **[write-the-weekly-update](./write-the-weekly-update/SKILL.md)** | Write this week's project status update from last week's report and current evidence, covering what was finished, which milestones moved, which blockers persist and how long, and what decisions are needed. | [Download](https://github.com/jsconu/pmo-skills/releases/latest/download/write-the-weekly-update.zip) |
