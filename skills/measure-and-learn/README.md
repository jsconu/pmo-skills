# Measure and learn

Money, metrics and lessons.

| Skill | What it does | Claude upload |
| --- | --- | --- |
| **[check-the-success-metrics](./check-the-success-metrics/SKILL.md)** | Compare success metric definitions, targets and direction with the latest observations, showing movement against each target, missing measures and questions to ask. | [Download](https://github.com/jsconu/pmo-skills/releases/latest/download/check-the-success-metrics.zip) |
| **[find-recurring-lessons](./find-recurring-lessons/SKILL.md)** | Compare decisions and their outcomes across comparable projects to find candidate lessons, the counterexamples, and the limits on applying them elsewhere. | [Download](https://github.com/jsconu/pmo-skills/releases/latest/download/find-recurring-lessons.zip) |
| **[review-the-budget](./review-the-budget/SKILL.md)** | From a budget, logged hours, rate assumptions and expenses, calculate actual spend, variance against budget and any unexplained gaps, with every figure traceable. | [Download](https://github.com/jsconu/pmo-skills/releases/latest/download/review-the-budget.zip) |
| **[run-the-retrospective](./run-the-retrospective/SKILL.md)** | From a project's charter, decision history, delivery evidence and closeout notes, write a retrospective covering what happened, which interventions helped and what to repeat, with lessons specific enough for the next PM to use. | [Download](https://github.com/jsconu/pmo-skills/releases/latest/download/run-the-retrospective.zip) |
