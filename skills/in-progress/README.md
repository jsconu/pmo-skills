# In Progress

Beta. These skills are public on purpose: try them and tell me what breaks. Each one is being compared blind against a plain assistant before it moves to a stable bucket. They are not in the plugin yet, and they can change without warning.

Install one directly:

```bash
npx skills@latest add jsconu/pmo-skills --skill=<name>
```

- **[ask-justin](./ask-justin/SKILL.md)**: Ask which skill fits the moment you're in. User-invoked.
- **[debrief-the-meeting](./debrief-the-meeting/SKILL.md)**: Turn a transcript into decisions, actions and owners, keeping suggestions, requests and acceptances apart.
- **[challenge-my-status](./challenge-my-status/SKILL.md)**: Find the few claims in a status draft a sponsor would challenge, with both sources and replacement wording.
- **[trace-the-impact](./trace-the-impact/SKILL.md)**: Trace an upstream slip to what's exposed, what can proceed and how much buffer is left.
