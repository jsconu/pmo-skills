# Decision log

Keep this with the meeting minutes. One row per decision. Fill it at the close of the meeting from the chair's recap or the approved minutes, not from the agenda.

| # | Decision requested | Actual decision | Approved by | Date | Evidence reference | Owner | Expected outcome | Next review date | Observed outcome | Outcome source | Close / adjust / revisit |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| 1 | | | | | | | | | | | |

Rules:

- **Expected outcome** is specific and checkable: what should be true, by when. "Smoke tests finish before Friday's interface delivery" works; "testing goes better" doesn't.
- If the group didn't decide, write **Open** in Actual decision and leave Approved by blank.
- At the next review, fill **Observed outcome** from fresh evidence. If there is none, write **Outcome unknown**. An approval only shows what was authorised, not what happened.
